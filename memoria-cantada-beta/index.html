Explorar por territorio

Una copla para cada isla.

El mapa reúne letras relacionadas con cada isla por los lugares, personas, devociones o elementos que mencionan. No atribuye el origen de una copla.

Elige una isla

Una misma letra puede aparecer en varias islas. La relación es temática o territorial, nunca una afirmación sobre dónde fue compuesta.

Toca una isla para ver las letras relacionadas.

Memoria colectiva

Una letra vive mientras alguien la recuerda y la canta.

Memoria Cantada no pretende fijar una única versión ni atribuir orígenes que desconocemos. Quiere conservar las coplas, los estribillos, sus variantes y las pequeñas historias que explican cómo llegaron hasta nosotros.
